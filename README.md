# YiYi-ChoiceClic

SillyTavern 的伊依动态行动选项点击扩展。

- 识别最新 AI 回复中的 `1.` / `2.` / `3.` 三条行动。
- 单击选中，再次点击取消，支持多选。
- 多选执行顺序按照点击顺序。
- 可直接执行，也可先填入输入框继续补充。
- 输入框已有内容时，会作为补充与所选行动一起发送。
- Swipe 后重新识别最新回复。

## 安装

在 SillyTavern 的扩展管理中选择 **Install Extension / 安装扩展**，输入本仓库地址：

`https://github.com/steep-47/YiYi-ChoiceClic`

安装后刷新或重启 SillyTavern。
